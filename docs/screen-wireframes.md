
# JobTrack — Screen Wireframes

## 1. Login Screen
- Application logo and name
- Email input
- Password input
- Login button
- Link to registration page

## 2. Registration Screen
- Full name input
- Email input
- Password input
- Confirm password input
- Create account button
- Link to login page

## 3. Dashboard
- Sidebar navigation
- Total applications card
- Pending applications card
- Interview applications card
- Offers received card
- Application status chart
- Recent applications table

## 4. Applications Screen
- Applications heading
- Add application button
- Search bar
- Status filter
- Applications table
- Edit and delete actions

## 5. Add/Edit Application Screen
- Company name
- Job title
- Job location
- Job type
- Application date
- Application status
- Job description
- Save button

## 6. Interview Management Screen
- Upcoming interviews
- Interview date and time
- Interview type
- Interview notes
- Interview outcome

## 7. Profile and Settings Screen
- User information
- Update profile option
- Change password option
- Logout button

## Navigation Flow

Login → Dashboard → Applications → Add/Edit Application

Dashboard → Interview Management

Dashboard → Profile and Settings

Note: These are planned screen structures.
The final UI may be refined during frontend development.
